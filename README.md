# 南京地铁客流量看板

南京地铁线网及各线路每日客流量的交互式查询看板。

数据来源：微博 [@南京地铁](https://weibo.com/u/2638276292) 每日发布的「#昨日客流#」公告，解析各线路客运量后整理而成。

## 在线访问

https://gisyq.github.io/nanjing-metro-flow/

## 页面功能

- **核心指标**：最新一日线网客运量、近 30 日日均、历史单日峰值、数据覆盖天数
- **趋势图**：支持近 30 天 / 90 天 / 1 年 / 全部区间切换，长区间自动按周均聚合，虚线为 7 日移动平均
- **分线路对比**：15 条线路（含 S1—S9 市域线）可多选，折线联动同一时间范围
- **线路构成**：最新一日的各线路客运量排行
- **日历热力图**：按年份查看客流强度分布，点击格子查看当日明细
- **停运标注**：官方通报的线路停运期在趋势图（橙色底纹）、热力图（橙色边框）、明细表（「停运」标签）中一并标出，悬停可查看停运原因与涉及线路
- **明细表**：按日期/星期/总计/各线路排序，支持日期搜索、分页、导出 CSV

## 数据说明

- 单位：万人次
- 时间范围：2012-09-11 起，累计 5100+ 天（每日自动递增），覆盖率 99.7%
- 缺失 17 天，均已逐日回查官方微博确认为官方未发布（节假日停更、暴雪停发、竞猜帖替代等），非抓取遗漏
- 微博文本横跨十余年，写法几经变化，已统一归一化：
  - 2012–2013 年用中文数字：`一号线`、`二号线`
  - 2014–2016 年用阿拉伯数字：`1号线`、`S1号线(机场线)`
  - 2017 年起用线路简称：`S1机场线`、`S3宁和线`、`S7宁溧线`、`S9宁高线`
- 线路按实际开通时间出现，开通前对应字段为空：
  1、2 号线（2012）→ 10 号线、S1（2014）→ 3 号线、S8（2015）→ 4 号线（2017）→ S3、S7、S9（2018）→ S6（2021）→ S2（2026）
- 5 号线、6 号线、7 号线开通前的日期对应字段为空
- 停运期间对应线路标注为「停运」而非空值，当日客流偏低属真实情况。已标注 6 段共 134 天：2021 年禄口机场疫情（S1/S7/S9）、2022 年疫情（S1/S6/S7/S9）、2024 年 7 号线全线贯通割接施工、2025 年春节 5 号线、2026 年台风「巴威」（6 条市域线）与「白海豚」（S9）
- 少量数据取自官方同一条帖中的合并播报或后续说明（如暴雪期间「#出行提示#」披露的线网总量），此类记录只有总量、无分线路拆分
- 单日数值为官方发布口径，转载引用请以官方发布为准

## 技术说明

整个看板是一个单文件静态页面（`index.html`），内联全部数据与样式，无外部依赖，可离线打开。图表为手写 SVG 绘制，不依赖任何图表库。

## 更新机制

数据每天 09:40 自动更新一次（官方「#昨日客流#」通常 09:00 左右发布）。更新流程：抓取微博最新公告 → 解析分线路数据 → 重建 `index.html` → 推送本仓库 → GitHub Pages 自动重新部署。

因此本仓库的提交记录即数据更新记录，每次提交对应一天的抓取结果。
