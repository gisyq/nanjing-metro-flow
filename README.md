# 南京地铁客流量看板

南京地铁线网及各线路每日客流量的交互式查询看板。

数据来源：微博 [@南京地铁](https://weibo.com/u/2638276292) 每日发布的「#昨日客流#」公告，解析各线路客运量后整理而成。

## 在线访问

https://gisyq.github.io/nanjing-metro-flow/

## 页面功能

- **核心指标**：最新一日线网客运量、近 30 日日均、历史单日峰值、数据覆盖天数
- **趋势图**：支持近 30 天 / 90 天 / 1 年 / 全部区间切换，长区间自动按周均聚合，虚线为 7 日移动平均
- **分线路对比**：15 条线路（含 S1—S9 市域线）可多选，折线联动同一时间范围
- **线路构成**：最新一日的各线路客运量排行
- **日历热力图**：按年份查看客流强度分布，点击格子查看当日明细
- **明细表**：按日期/星期/总计/各线路排序，支持日期搜索、分页、导出 CSV

## 数据说明

- 单位：万人次
- 时间范围：2019-12-31 起，覆盖 2400+ 天
- 早期微博使用「S1机场线 / S3宁和线」等写法，已做归一化处理
- 5 号线、6 号线、7 号线开通前的日期对应字段为空
- 少数日期因官方未发布或疫情停更而缺失
- 单日数值为官方发布口径，转载引用请以官方发布为准

## 技术说明

整个看板是一个单文件静态页面（`index.html`），内联全部数据与样式，无外部依赖，可离线打开。图表为手写 SVG 绘制，不依赖任何图表库。

## 更新机制

数据每天 09:40 自动更新一次（官方「#昨日客流#」通常 09:00 左右发布）。更新流程：抓取微博最新公告 → 解析分线路数据 → 重建 `index.html` → 推送本仓库 → GitHub Pages 自动重新部署。

因此本仓库的提交记录即数据更新记录，每次提交对应一天的抓取结果。
